# Singh Academy V60.6

V60.6 is the current Singh Academy review/deployment package. It preserves the approved public UI and V60.5 billing/enrollment behavior while updating the certificate master to the requested Singh Academy certificate theme for all issued courses.

Key current behaviors:
- one learner owns their own enrollment, membership, progress, answers, payments, invoices and certificate state
- individual paid-course invoices are visible in Client Admin Course Purchases
- active membership shows Membership Access on covered course cards
- certificate output uses the same Singh Academy layout/theme across all courses, with dynamic student/course/date/certificate data
- Stripe test and PayPal sandbox review configuration remain supported

Use Node 22.x. Start with `START-HERE-V60.6.md`.
